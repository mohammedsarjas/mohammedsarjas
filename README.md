## Featured Project

### 📚 Library Ontology

An ontology for representing library and bibliographic information.

**Repository:** [Library Ontology](https://github.com/mohammedsarjas/library-ontology)

The project represents concepts such as:

- Book
- Author
- BookCopy
- Publisher
- Subject
- LoanMember

It also models relationships between books, authors, publishers,
subjects, copies, and library members.
